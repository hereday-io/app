# UX_PATTERNS.md

## Philosophy

The product should feel:
- Premium
- Effortless
- Clean
- Fast

Inspired by:
- Apple Maps
- Strava
- Nike Run Club

---

## Core UX Principles

### 1. Map First

- Map is always the hero
- UI should support, not compete

---

### 2. Reduce Cognitive Load

- Show only what matters
- Hide complexity behind interaction

---

### 3. Default to Beautiful

- Even with no customization:
  → It should look good

---

### 4. Mobile First (Viewer)

- Large touch targets
- Minimal overlays
- Quick-glance info

---

## Layout Patterns

### Editor

- Top bar (primary actions)
- Map center
- Side panel (details)

---

### Public Map

- Full screen map
- Bottom sheet (mobile)
- Minimal controls

---

## POI Design

- Clear icons per type
- Tap → card opens
- Card includes:
  - title
  - description
  - image (optional)

---

## Start / Finish

- Must be instantly recognizable
- Use strong visual markers
- Avoid subtle styling

---

## Legend

- Simple
- Compact
- Optional toggle

---

## Interactions

- Tap > hover (mobile first)
- Smooth transitions
- No jarring UI jumps

---

## States

Always design for:
- Empty states
- Loading states
- Error states

---

## Premium Feel Checklist

Before shipping UI, ask:
- Does this feel clean?
- Is anything cluttered?
- Is spacing generous?
- Is hierarchy obvious?

---

## Anti-Patterns

Avoid:
- Overcrowded screens
- Tiny tap targets
- Too many colors
- Excessive text
- Complex menus

---

## Default Rule

If unsure:
👉 Remove something instead of adding more
