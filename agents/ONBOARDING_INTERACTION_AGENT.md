## 🔍 Audit Areas

### 1. Map Affordance

Can users tell:
- They can click to draw?
- They can drag points?
- They can interact?

---

### 2. Feedback While Drawing

Evaluate:
- Route previews
- Cursor feedback
- Snapping clarity

---

### 3. POI Placement

Evaluate:
- Selection → placement flow
- Feedback before placement
- Visual confirmation

---

### 4. State Visibility

Can users tell:
- Which route is active?
- What mode they’re in?
- What happens next?
